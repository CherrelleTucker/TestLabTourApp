**Title:** Future feature: Virtual tours for historical stops using Auburn lidar scans

**Label:** enhancement

**Body:**

## Feature Request

Historical tour stops (legacy facilities that are no longer active) could potentially include virtual tours based on Auburn University lidar scans.

### Context
- Auburn has performed lidar scanning of MSFC facilities
- These scans could provide immersive 3D walkthroughs of historical test stands
- Particularly valuable for legacy facilities that are no longer accessible

### Implementation considerations
- Identify which historical stops have Auburn lidar data available
- Determine format/access method for lidar scan data
- Evaluate embedding options (iframe, WebGL viewer, etc.)
- Consider file size and bandwidth for iPad deployment
- May need offline caching strategy for large 3D assets

### Benefits
- Preserves institutional knowledge of decommissioned facilities
- Provides immersive experience for locations no longer on active tours
- Educational value for understanding historical test programs
